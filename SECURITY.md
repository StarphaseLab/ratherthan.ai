# Security Policy

## Reporting a vulnerability

Please report security issues privately to **lab@starphase.sk** rather than opening a public issue. You'll get an acknowledgement within a week and a good-faith fix or response within 90 days.

In scope, especially:

- Any way to make the site store or display content that bypassed moderation.
- Any way to recover voter identities, IP addresses, or deletion tokens from stored data.
- Any way the future submission tooling could transmit more than the user approved.

There is no bug bounty — the entire project budget is one domain name — but you'll get public thanks and our sincere gratitude, which we are told is priceless.
